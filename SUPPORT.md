# Support

Support is provided through
[GitHub Issues](https://github.com/Pigbibi/TelegramAutoSignBot/issues) on a
best-effort basis.

Before opening an issue, read the README, search existing reports, run the
workflow manually, and inspect the failing step. Include the commit, expected
behavior, actual behavior, and a short redacted log excerpt.

Do not include session strings, API credentials, target lists, phone numbers,
or private messages. Account restrictions and destination-bot behavior are
controlled by external services and cannot be resolved by this project.

Follow [SECURITY.md](SECURITY.md) for vulnerabilities or credential exposure.
